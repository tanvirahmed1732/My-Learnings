# Session 29 - Exploratory Data Analysis

This folder contains materials and exercises for Session 29 of the Data Science Mentorship Program (DSMP), focusing on Exploratory Data Analysis (EDA) techniques.

## Overview

Exploratory Data Analysis (EDA) is a crucial step in the data analysis process that involves examining and understanding the structure, patterns, and relationships within a dataset. This session covers fundamental EDA concepts and practical techniques using the Titanic dataset.

## Contents

- **session_on_eda.ipynb**: Jupyter notebook containing the complete EDA session, including:
  - Dataset loading and initial exploration
  - Understanding the purpose and benefits of EDA
  - Column type classification (numerical, categorical, mixed)
  - Univariate analysis techniques
  - Distribution analysis (normal, skewed, bimodal, uniform)
  - Measures of dispersion (range, variance, standard deviation, IQR)
  - Step-by-step univariate analysis on numerical columns
  - Practical examples with the Age column

## Dataset

The session uses the Titanic dataset (train.csv), which contains passenger information from the Titanic disaster. The dataset includes features such as age, fare, passenger class, gender, and survival status.

## Key Topics Covered

### Why EDA?
- Model building preparation
- Analysis and reporting
- Validating assumptions
- Handling missing values
- Feature engineering
- Detecting outliers

### Univariate Analysis
- Distribution analysis and shape identification
- Identifying data issues (outliers, skewness, missing values)
- Descriptive statistics computation
- Visualization techniques (histograms, box plots, density plots)
- Outlier detection and handling

### Distribution Shapes
- Normal distribution
- Skewed distributions (positive/negative)
- Bimodal distribution
- Uniform distribution

### Measures of Dispersion
- Range
- Variance
- Standard deviation
- Interquartile range (IQR)

## Learning Objectives

By the end of this session, participants will be able to:
- Understand the importance and applications of EDA
- Classify dataset columns by type
- Perform univariate analysis on numerical data
- Interpret distribution shapes and measures of dispersion
- Identify and handle outliers and missing values
- Apply EDA techniques to real datasets
