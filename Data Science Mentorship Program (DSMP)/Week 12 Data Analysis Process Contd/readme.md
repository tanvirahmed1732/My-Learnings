# Week 12: Data Analysis Process Contd

This folder contains materials, notebooks, and exercises for Week 12 of the Data Science Mentorship Program (DSMP) from CampusX.

## Overview

Week 12 continues the comprehensive Data Analysis Process covered in Week 11, with a focus on advanced exploratory data analysis techniques and hands-on data cleaning case studies. This week builds upon the foundational concepts of data gathering, assessment, and cleaning by applying them to real-world datasets.
