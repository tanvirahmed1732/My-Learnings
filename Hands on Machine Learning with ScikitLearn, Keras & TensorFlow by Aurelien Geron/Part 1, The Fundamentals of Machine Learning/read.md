# Part 1 — The Fundamentals of Machine Learning ✅

**Purpose:** This folder contains my reading notes and hands-on practice for *Part 1* of Aurélien Géron's *Hands-On Machine Learning*. I will reproduce book examples, take concise notes, and add my own experiments to deepen understanding.

## What to expect
- **Topics:** Supervised learning basics, training and evaluation, linear models, decision trees, model complexity, regularization, and fundamental ML workflows.
- **Files:**
  - `notebooks/part1/` — chapter-specific notebooks (e.g., `ch01_introduction.ipynb`).
  - `scripts/` — small reproducible scripts and utilities.
  - `data/` — datasets used for experiments.
  - `notes.md` — concise summaries and takeaways for quick review.

## Workflow ⚙️
1. Read the chapter and take quick notes.
2. Reproduce the book's code in a notebook under `notebooks/part1/`.
3. Create at least one small extension or experiment per notebook.
4. Document findings in `notes.md` and commit often with clear messages.

## Conventions & Tips 💡
- Name notebooks with `ch##_short-title.ipynb`.
- Use a virtual environment (`venv`/`conda`) and pin deps in `requirements.txt`.
- Make experiments reproducible (set random seeds, record dataset splits).
- Keep examples small and focused — aim for clarity over cleverness.
