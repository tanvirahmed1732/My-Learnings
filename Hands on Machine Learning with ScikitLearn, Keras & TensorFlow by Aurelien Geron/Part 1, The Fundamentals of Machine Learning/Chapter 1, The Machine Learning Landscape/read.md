# Chapter 1 — The Machine Learning Landscape ✅

**Purpose:** Notes and practical exercises for Chapter 1 of *Hands-On Machine Learning* by Aurélien Géron. This file summarizes key ideas, suggests exercises, and provides a short checklist for hands-on practice.

## Summary
- Machine learning (ML) is about building models that can learn patterns from data and make predictions or decisions.
- Main paradigms: **supervised learning**, **unsupervised learning**, and **reinforcement learning**.
- Common tasks: regression, classification, clustering, and dimensionality reduction.
- Important workflow elements: training, validation, testing, cross-validation, and model selection.

## Key Concepts
- Instance, features, label (target)
- Training set vs. test set; overfitting vs. underfitting
- Bias–variance tradeoff
- Evaluation metrics (e.g., accuracy, precision/recall, RMSE, F1)
- Importance of data preprocessing and feature engineering

## Practical Exercises
1. Create `notebooks/part1/ch01_machine_learning_landscape.ipynb`.
2. Load a small dataset (e.g., Iris or California housing) and inspect features/targets.
3. Split data into train/test sets; train a simple model (e.g., LinearRegression or LogisticRegression).
4. Evaluate with appropriate metrics and plot results (confusion matrix, scatter plots).
5. Try a simple cross-validation run and compare results.
