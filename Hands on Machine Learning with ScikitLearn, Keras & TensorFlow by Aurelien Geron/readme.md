# Hands-On Machine Learning with Scikit-Learn, Keras & TensorFlow — Notes & Practice ✅

**Purpose:** Learn and practice the content of the book *Hands-On Machine Learning with Scikit-Learn, Keras & TensorFlow* by Aurélien Géron. This folder contains code examples from the book and my own practice exercises.

## Structure
- `notebooks/` — practice notebooks and reproductions of book examples
- `scripts/` — standalone scripts and utilities
- `data/` — datasets used for experiments
- `models/` — saved models and checkpoints

## Workflow ⚙️
1. Read the relevant chapter in the book.
2. Reproduce the book's code here under a chapter-specific notebook or script (e.g., `ch02_linear_regression.ipynb`).
3. Extend or modify examples with my own experiments.
4. Commit frequently with clear, descriptive messages.

## Notes & Conventions 💡
- Use `venv` or `conda` for environment management.
- Track dependencies in `requirements.txt`.
- Keep experiments reproducible (set seeds, fix data splits).

---

*Start each notebook or script with a short description and a reference to the book chapter.*
